Syntax Reference

A quick introduction to the commands used in the current interpreter.

Variables vforge score = 10

Create a variable and assign it a value.

Output vdisr "Hello, VEXA!"

Print a value or expression.

Input vxin "Your name?" -> name

Request input and store it in a variable.

Conditions vwhen score > 5

Begin a conditional block. Use velse for the alternative branch and vdone to finish.

Finish a Block vdone

Close a supported conditional block.

Stop Execution vhalt

Stop the current program.
